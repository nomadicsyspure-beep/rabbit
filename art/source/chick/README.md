# 병아리 원본 이미지

이 폴더에 병아리 캐릭터 원본(PNG, GIF)을 올린다.

## 올리는 법
GitHub에서 이 폴더 → **Add file → Upload files** → 파일 끌어다 놓기 → **Commit changes**

## 파일 이름
방향이 있는 그림이면 주인공(`art/source/hero`)과 같은 방향 단어를 넣는다.

- 멈춤 PNG: `front`, `front-right`, `right`, `back-right`, `back`, `back-left`, `left`, `front-left`
- 이동 GIF: `south`, `south-east`, `east`, `north-east`, `north`, `north-west`, `west`, `south-west`

방향이 하나뿐이면 이름은 자유.

## 있으면 좋은 것
- 배경이 투명
- 주인공과 같은 크기(256×256)
