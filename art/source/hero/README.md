# 주인공(토끼) 원본 이미지

이 폴더에 주인공 캐릭터 원본을 올린다. 게임에서 쓰는 스프라이트는 여기서 잘라 `src/assets/`에 만든다.

## 올리는 법
GitHub에서 이 폴더 → **Add file → Upload files** → 파일 끌어다 놓기 → **Commit changes**

## 파일 이름
동작이 드러나게 짓는다. 한 파일에 동작 하나.

- `hero-idle.gif` 대기
- `hero-walk.gif` 걷기
- `hero-attack.gif` 공격
- `hero-hit.gif` 피격
- `hero-down.gif` 쓰러짐
- `hero-front.png` 정면 일러스트 등 정지 이미지

## 있으면 좋은 것
- 배경이 투명하거나 한 가지 단색
- 프레임마다 캐릭터 크기·위치가 일정
- 바라보는 방향이 한쪽으로 통일 (반대쪽은 게임에서 뒤집어 쓴다)
