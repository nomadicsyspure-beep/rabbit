# BM(수익 구조) 기획 · 출시 준비

원칙
- **광고 없음** (결정됨: 거슬리기만 함). 돈은 인앱 결제로만.
- 과금은 **시간 단축 + 꾸미기**. 무과금도 모든 콘텐츠를 깰 수 있어야 한다 ("뇌빼고 도파민"이라 막히는 벽을 만들지 않는다).
- 첫 출시는 경험치용 → 상품은 적게, 단순하게.

## 1. 재화

| 재화 | 얻는 곳 | 쓰는 곳 | 유료 |
|---|---|---|---|
| 골드 | 방치 수입, 스테이지 | 능력치·스킬 강화(등급 높을수록 비쌈), 나무 스킬 상자, 장비 제작 | X |
| 재료 (지역별) | 보물 상자, 재료 던전 | 장비 제작·강화 | X |
| 다이아 💎 | 미션·출석·업적·패스, 금 상자, 황금 몹, **결제** | 스킬 상자(은·금·전설), 동료·장비 소환, 꾸미기 | O |
| 보스의 정수 🔮 | 보스 레이드 (하루 3번) | 전설 장비 | X |
| 환생 깃털 🪶 | 환생 | 영구 강화 | X |

다이아 가치 기준: **1💎 ≈ 4원** (1,200원 = 300💎). 소환 1번(50💎) ≈ 200원.

무과금 다이아 수입 (지금 값): 일일 미션 170 + 출석 평균 약 80 + 황금 몹·금 상자 약 20 = **하루 약 270💎 (소환 5번)**.
→ 넉넉한 편. 출시 후 결제율이 낮으면 미션 보상을 줄이기보다 상품 가치를 올린다.

## 2. 상품 (원화, 구글 플레이 가격대)

| 상품 | 가격 | 내용 | 비고 |
|---|---|---|---|
| 다이아 S | 1,200원 | 💎 300 | 첫 구매 2배 |
| 다이아 M | 5,900원 | 💎 1,600 | 첫 구매 2배 |
| 다이아 L | 14,000원 | 💎 4,000 | 첫 구매 2배 |
| 다이아 XL | 33,000원 | 💎 10,000 | 첫 구매 2배 |
| **스타터 팩** (1회) | 2,900원 | 💎 500 + 희귀 이상 동료 확정 소환권 + 스킬북 5 | 가장 먼저 사게 되는 상품 |
| **월정액** | 4,900원 | 즉시 💎 300 + 30일간 매일 💎 100 (총 3,300) + 방치 수입 +20% | 매일 들어올 이유 |
| **프리미엄 패스** (30일 시즌) | 9,900원 | 패스 프리미엄 줄 (💎 약 3,000 + 전설 동료 1 + 시즌 병아리 색) | 이미 화면 있음 |
| 성장 패키지 | 4,900~9,900원 | 최고 스테이지 10·20·30·50 달성 시 열림: 다이아 + 재료 + 스킬북 | 막히는 구간에 맞춰 |
| 꾸미기 세트 | 3,900원 | 병아리 색 3 + 이펙트 색 2 묶음 | 다이아로도 낱개 구매 가능 |

설계 메모
- 가장 싼 상품(1,200원·2,900원)에 혜택을 몰아서 **첫 결제 문턱**을 낮춘다.
- 월정액은 하루 100💎 = 소환 2번: 무과금 대비 체감 +40% 정도.
- 전설 동료(토끼 기사·꼬마 마왕)는 소환 4%라 패스·스타터 팩으로 확정 획득 루트를 하나 둔다.

다이아를 더 쓰게 할 곳 (지금은 스킬 상자·소환·꾸미기)
- **스킬 상자가 주력 소비처**: S급은 금(💎150, 7%)·전설(💎450, 25%) 상자에서만 → 전설 10회(💎4,050 ≈ 16,200원)면 S급 평균 2.5개
- 재료 던전·보스 레이드 추가 입장: 50💎 (하루 1번까지)
- 장비 강화 재료 부족분을 다이아로 채우기
- (선택) 스킬 슬롯 프리셋 저장: 300💎

## 4. 출시 경로 (추천: 구글 플레이 먼저)

1. 웹 버전은 지금처럼 GitHub Pages에 둔다 (무료 체험·홍보 링크).
2. 앱 포장: Capacitor로 지금 웹 게임을 안드로이드 앱으로 감싼다 (코드 그대로).
3. 구글 플레이 개발자 등록: 25달러 1회.
   - **신규 개인 계정은 비공개 테스트에 테스터 12명이 14일 이상 참여해야 정식 출시 가능** → 테스터부터 모아 두기.
4. 결제: 플레이 스토어 앱은 구글 플레이 결제가 필수. 첫 버전은 서버 없이 기기에서 처리 (저장은 지금처럼 기기 안).
   - 앱을 지우면 저장이 사라진다 → 나중에 클라우드 저장(로그인) 추가.
5. 필요한 것: 앱 아이콘 512×512, 대표 그래픽 1024×500, 스크린샷 4장 이상, 개인정보처리방침 페이지 (수집하는 정보 없음), 콘텐츠 등급 설문.
6. 아이폰은 나중에 (맥 + 연 99달러 필요).
