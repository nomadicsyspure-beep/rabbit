# 기획 메모

## 컨셉
토끼 용사가 평소엔 알아서 사냥하며 크고(방치), 중요한 순간엔 직접 들어가 싸운다(뱀서라이크).
핵심은 **방치 모드에서 키운 게 액션 모드에서 체감되는 것**.

## 핵심 루프
자동사냥 → 골드 → 강화 → 보스 스테이지(10단위)는 직접 조작으로 클리어해야 진행 → (추후) 환생

## 결정 사항
- 플랫폼: 모바일 브라우저, 세로 화면, 터치 기준 (PC는 WASD로 확인용)
- 아트: 임시 도형으로 시작, 렌더러만 바꿔서 스프라이트로 교체
- 전투 엔진은 하나, 조종 주체만 다름 (AutoController / Joystick)
- 액션 모드는 공격 자동, 플레이어는 이동만. 플로팅 조이스틱
- 숫자 인플레이션 대응: 액션 모드는 방치 수치를 그대로 쓰지 않고
  **내 수치 ÷ 권장 수치 = 배율**(0.25~4배로 제한)로 환산해서 적용
- 탭 공격: 방치 화면을 탭하면 공격력의 50% 추가 피해
- 하단 탭 5개: 성장 / 장비 / 동료 / 던전 / 상점, 설정은 상단 아이콘

## 프로토타입(v0.1) 범위
- 방치: 자동사냥, 탭 공격, 골드, 스탯 3종(공격력·체력·공격 속도), 10킬마다 스테이지 진행, 10스테이지마다 보스 관문, 오프라인 보상(최대 8시간, 50%)
- 액션: 3분 생존 후 보스, 레벨업 카드 3택 1(무기 4종 + 패시브 3종, 각 최대 5레벨), 60초·120초 몰려오기 이벤트
- 던전 탭: 보스 도전, 연습 던전(보상 없음), 일일/주간(잠금)
