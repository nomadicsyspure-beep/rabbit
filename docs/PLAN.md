# 기획 메모

## 컨셉
병아리 용사가 평소엔 알아서 사냥하며 크고(방치), 중요한 순간엔 직접 들어가 싸운다(뱀서라이크).
핵심은 **방치 모드에서 키운 게 액션 모드에서 체감되는 것**.

## 핵심 루프
스테이지 직접 플레이(뱀서라이크) → 클리어하면 최고 스테이지 갱신 → 방치 수입 증가 → 능력치·스킬 강화 → 다음 스테이지 → (추후) 환생

- 방치 화면은 보여주기용. 스테이지가 바뀌지 않고, 최고 스테이지 기준 초당 골드만 쌓인다 (액션 중에도 쌓임)
- 스테이지는 1분: 60초 버티면 정예 몬스터 / 10단위 스테이지는 마왕 보스. 몹이 짙어지는 속도는 스테이지 길이와 상관없이 90초에 걸쳐

## 결정 사항
- 플랫폼: 모바일 브라우저, 세로 화면, 터치 기준 (PC는 WASD로 확인용)
- 아트: 주인공은 병아리. `art/source/chick`의 8방향 걷기·달리기 GIF를 `tools/chick_frames.py`로 정리해 쓴다 (멈춤은 걷기 첫 프레임, 쓰러짐은 눕힌 그림)
- 몬스터·스킬 이펙트·UI는 두 시트(`art/source/fx-sheet.webp`, `ui-sheet.webp`)에서 `tools/cut_sheets.py`로 잘라 쓴다. 시트에 없는 UI(도전 버튼, 강화 버튼 등)는 기존 것 그대로 둔다
- 몬스터 9종: 스테이지마다 일반/빠른/단단한 몬스터 외형이 바뀐다 (슬라임·박쥐·골렘 / 버섯·천사·달팽이 / 새싹·박쥐·골렘). 정예는 토끼 전사, 마왕은 악마. 쓰러지면 쓰러진 그림이 잠깐 남는다
- 배경은 흙바닥 (코드로 그린 무늬 + 시트의 돌·잎 장식)
- 이동은 출발할 때 느리게 시작해 가속한다 (최고 속도의 45%에서 출발, 약 0.3초 뒤 80%를 넘으면 달리기 그림). 방치 화면은 천천히 걸어서 걷기만
- 전체 템포는 빠르게, 몹은 많이·약하게: 쏟아지는 몹을 생각 없이 쓸어 담는 게 목표. 처치 때 쓰러진 그림·먼지·반짝임, 폭발·피격 때 화면 흔들림
- 스킬은 RPG처럼 영구: 골드로 배우고, 스킬 트리 3가지(피해 최대 30 / 발동 속도 최대 20 / 개수 최대 10)를 따로 강화하면 다음 스테이지에도 그대로. 스테이지에서는 장착한 4개만 자동 발동. 레벨업 카드(3택 1)는 없앴다
- 스킬 13종: 깃털 날리기·회오리·알 폭탄·화염 폭발·얼음 결정·치유·화염구·암흑 구체(UI 시트 아이콘) + 회전 베기·번개 연쇄·블랙홀·별똥별·빛의 기둥(이펙트 그림을 나무 틀에 넣은 아이콘)
- 밸런스보다 도파민: 장착 스킬이 많을수록 몹이 더 몰려오고, 처치마다 골드, 연속 처치 콤보 표시
- 캐릭터 레벨: 스테이지의 경험치 보석이 영구 경험치로 쌓인다. 레벨마다 공격력·체력 +5%
- 전투 엔진은 하나, 조종 주체만 다름 (AutoController / Joystick)
- 액션 모드는 공격 자동, 플레이어는 이동만. 플로팅 조이스틱
- 스테이지 설정 (저장됨): 왼쪽 위 AUTO = 플레이 전체 자동, 멀미 안 나게 최고 속도의 65%로 천천히 꺾으며 (몹 무리에 알맞은 거리로 붙어 둘레를 돌며 쓸고, 붙은 몹·보스는 피하고, 보물 상자를 주우러 감. 스킬도 자동. 조이스틱을 쓰면 그동안 직접 조종) / 아래 '스킬 자동·수동' = 수동이면 스킬 칸을 눌러야 발동 (암흑 구체는 늘 켜짐)
- 보물 상자: 스테이지에서 12초마다 근처에 나온다. 주우면 맵의 경험치 보석을 전부 끌어오고 골드 보너스
- 한 방향으로 꾹 누르기 방지: 움직이는 중엔 새 몹의 80%가 가는 방향 앞쪽에서 나오고, 멀어진 몹도 앞쪽으로 다시 온다. 같은 방향으로 1.5초 넘게 달리면 앞에 벽(2.5초마다), 방향을 안 바꾸면 벽이 점점 두꺼워지고 아파지며 두 번째부터는 정면 돌진 떼도 온다 (꾹 누르면 대략 10초면 쓰러짐). AUTO가 조종하는 동안은 이 벌칙에서 빠진다
- 몹 움직임: 일반은 옆으로 흔들리며 쫓아오고, 빠른 몹은 가는 길목을 앞질러 막는다
- 패턴 웨이브 (11초마다 돌아가며): 포위(빈틈 한 곳) / 돌진(옆에서 한 줄로 가로질러 감) / 벽(앞을 막음)
- 피버: (피버 중엔 AUTO로 천천히 움직여도 달리기 그림) 게이지가 처치 500마리만큼 차면(콤보와 상관없이 쌓이고, 피버가 끝나면 0부터) 10초 FEVER TIME. 장착 스킬 모든 가지(피해·발동 속도·개수) +5, 쿨다운 즉시 충전, 이동 속도 1.7배, 몹 2.5배, 피버 중 처치 골드 2배. 시간 아래 FEVER 게이지, 화면 테두리·병아리 금빛 (`src/modes/action.ts`의 FEVER_*)
- 타격감: 맞을 때 불꽃 파편, 치명타(15%, 피해 2배, 주황색 큰 숫자 + 더 세게 밀림), 맞은 몹이 납작해졌다 돌아옴, 쓰러질 때 몸 색 조각, 화염구·깃털 꼬리, 보석 주울 때 반짝, 100콤보마다 축하 연출, 번개는 빛나는 두 겹 선
- 몹 난이도 배율: 체력 ×1.8, 부딪힐 때 피해 ×1.5, 정예 체력 1800, 마왕 체력 5000 (`src/modes/action.ts`의 MOB_HP, MOB_DMG, ELITE_HP, BOSS_HP)
- 직접 플레이 테스트용으로 원래 값 사용 (`COST_OVERRIDE`·`DIAMOND_OVERRIDE` = null). 값 올림: 스킬 강화 기본 D 40 · C 100 · B 250 · A 700 · S 2,000, 상자 나무 = 방치 10분어치 / 은 💎40 / 금 💎150 / 전설 💎450, 소환 💎60 (10회 540), 장비 제작 재료 ×1.5 · 골드 ×2. 설정에 '테스트: 다이아 1,000 지급' 버튼
- 가로 모드는 스테이지에서만: '가로' 버튼이 전체 화면 + 가로 고정을 요청 (아이폰은 직접 돌리기). 가로 화면에선 왼쪽 절반 = 조이스틱, 오른쪽 = 스킬 칸 4개 (두 손 조작). 메인 화면은 세로 그대로
- 장비 (`src/data/gear.ts`): 무기·모자·장신구 17종. 지역 재료 + 골드로 제작, +15까지 강화(+1마다 효과 15%↑). 무기 = 공격력% + 그 스킬을 공짜로 한 줄 더 쏨(장착 칸 안 씀), 모자 = 체력%, 장신구 = 자석·상자 등급·콤보 시간·치명타·피버 게이지·골드. 전설(마왕의 검·왕관)은 보스의 정수 필요. 그림 생기기 전까지 이모지 아이콘
- 스킬북: 📕 1권 = 스킬 은 상자 1회 (보물 상자·재료 던전에서 드랍)
- 도감: 처음 잡은 몬스터·처음 만든 장비 하나마다 공격력·체력 +1%
- 환생: 최고 스테이지 20부터. 골드·최고 스테이지·능력치 강화 초기화, 환생 깃털 획득 → 공격력 +10% / 골드 +15% / 경험치 +15% 영구 강화
- 동료 (`src/data/pets.ts`): 몬스터 그림을 그대로 쓰는 9종 (보통·희귀·전설). 하나만 데리고 다니고 방치·스테이지 둘 다 따라다님. 자석·골드·상자·체력·치명타·피버(능력치) / 박쥐 공격·버섯 포자 폭발·천사 회복(직접 행동). 소환으로 겹치면 레벨 업(최대 10)
- 상점 (`src/data/shop.ts`, `src/ui/shop.ts`): 다이아 소환(동료·장비, 원래 값 1회 50 / 10회 450, 소환권 먼저), 병아리 색 8종(몸통 노랑만 색상 회전, 무지개는 시간에 따라 돈다), 스킬 이펙트 색 6종(이펙트 그림 색상 회전, `src/battle/tint.ts`), 다이아 충전(결제 준비 중)
- 광고 보상은 넣지 않는다 (사용자 결정: 거슬리기만 함)
- 미션 버튼(방치 화면 왼쪽 위, 받을 게 있으면 빨간 점): 일일 미션 6개 + 모두 완료 보너스, 7일 반복 출석, 단계별 업적 10종, 패스 30레벨(무료 보상, 프리미엄 줄은 결제 준비 중). 패스 경험치는 스테이지 도전·미션·업적으로
- 던전 탭 (최고 스테이지 난이도): 재료 던전(하루 2번, 45초, 3초마다 상자) / 보스 레이드(하루 3번, 90초 제한, 잡몹 대폭 줄임. 마왕이 장판(빨간 원이 차오르면 폭발)·나선 탄막·돌진·박쥐 소환을 돌아가며, 체력 절반부터 2페이즈로 더 빠르고 많이. 이기면 보스의 정수 3개(45초 안이면 4개), 져도 절반 넘게 깎으면 1개) / 무한 모드(시간 제한 없음, 1분마다 다음 지역, 45초마다 정예, 최고 기록 저장)
- AUTO는 레이드 장판 안에 있으면 바깥으로 빠져나간다 (완벽하진 않음 — 직접 피하는 게 더 잘 산다)
- 웨이브 몹은 발밑 원 테두리 색으로 구분하고 더 아프다 (피하라는 신호): 돌진 = 빨강, 피해 ×2.2 / 포위 = 보라, ×2 / 벽 = 파랑, ×1.5 (`src/modes/action.ts`의 CHARGE_DMG 등, 색은 `src/battle/renderer.ts`의 TINT_RINGS). 몹 그림 채도 0.8, 배경도 채도·밝기를 조금 낮춤
- 구급상자 몹: 0.4% 확률, 단단함(체력 70×), 잡으면 체력 회복템(최대 체력 35%, 상자처럼 끌려옴)
- 황금 몹: 크기 2배(반경 22), 금색으로 칠함, 체력 80×, 부딪히면 아픔, 18초. 170px 안으로 다가오면 도망치고 멀면 느릿느릿 어슬렁. 잡으면 골드(몹 골드 ×150) + 💎5 + 금 상자
- 보물 상자는 240px(또는 보석 자석의 3배) 안이면 저절로 끌려온다 (`CHEST_MAGNET`)
- 스킬 30종 (`src/battle/weapons-more.ts`에 17종 추가: 부메랑·반딧불·독안개·지진·낙뢰·얼음 창·별 폭죽·불길·거대 알·흡혈·성스러운 십자·중력 폭탄·레이저·눈보라·폭죽·도깨비불·깃털 폭풍). + 설정만으로 만드는 스킬 4종류(날리기·내리꽂기·파동·장판, 그림 이름@색상으로 색 구분) 26종 = 총 56종. 나중에 추려서 밸런스 조정 예정. 지금은 전부 스킬북 없이 배움. 스킬 이펙트·범위는 전부 0.7배 (`src/battle/weapons.ts`의 FX)
- 스킬 탭: 위에 장착 중 4칸 고정, 아래 5열 아이콘 격자만 스크롤. 아이콘을 누르면 설명·배우기·가지 강화·장착, 칸이 가득이면 바꿀 스킬을 골라 교체
- 장비 겉모습 (`src/battle/outfit.ts`): 지금은 무기만 바라보는 쪽 옆 36px에 둥둥 (모자·등은 `SHOW_BODY_GEAR`로 꺼 둠). 모자 = 머리 위, 등 = 몸 뒤(위를 볼 땐 앞). 머리 위치는 프레임마다 그림의 투명 부분을 읽어 자동으로 찾는다. 그림은 `src/assets/gear`에 `<id>-<방향>.png`(기준 프레임 `art/templates` 위에 그린 레이어) / 무기는 `<id>.png`. 그림이 없으면 임시 아이콘·코드 모양
- 등 장비 5종 추가 (가죽 가방·빨간 망토·박쥐 날개·천사 날개·마왕의 망토). 새 효과: 이동 속도
- 출발 속도: 목표 속도의 85%에서 시작, 가속 세기 6 (`src/battle/engine.ts`의 START_SPEED, ACCEL)
- 주요 버튼(도전·강화·배우기 등)은 파란색 대신 UI 시트 나무 틀 + 밝은 나무색. 스크롤바는 전부 숨김. 설정에 전체 화면 버튼
- 스킬 형태 4가지 (`SkillType`): 공격형(주변 광역) / 보조형(적을 골라 맞힘) / 디버프형(상태 이상) / 버프형(나를 강화). 장착 칸은 형태마다 한 칸 (공격·타겟·디버프·버프 순), 같은 형태를 끼우면 바꿔 낀다. 스킬 탭은 형태별 색으로 나뉨 (새 그림 없이 색만)
- 디버프 (몹 상태): 기절·공포·혼란·취약(받는 피해 ×1.5)·표식(치명타 확정)·화상/동상/맹독(지속 피해, 맹독은 옮음)·저주(쓰러지면 폭발)·시간 정지. 보스는 기절·공포·혼란에 안 걸림. 표시는 도형(별·느낌표·물음표·색 고리)
- 버프 (병아리): 보호막·분노·신속·질주·가시 갑옷·재생·행운·자석 폭풍·무적·축복. 피해 가지 = 세기, 개수 가지 = 지속 시간(초). 스킬 총 88종, 새 스킬 그림은 기존 이펙트를 색만 바꿔 씀

- 장비 → 유물 시스템으로 교체 (`src/data/relics.ts`, 옛 `gear.ts` 삭제): 부위 없이 유물 6칸 아무 데나 (같은 유물은 하나). 칸은 역대 최고 스테이지로 열림 (처음 2칸 · 5 · 10 · 20 · 30). 유물 30종 = 지역 5곳 × 6개 (들판 일반 · 버섯 숲/얼음 희귀 · 용암 영웅 · 마왕 전설(정수)), 등급 색 틀. 유물마다 공격력/체력% · 수치(자석·상자·콤보·피버·골드·치명타·이동) · 발동 효과(회피·보호막·냉기·반격 폭발·치명타 번개/빙결·처치 폭발·흡혈·발자국 장판) · 공짜 스킬(깃털·화염구·번개·유성·블랙홀·빛의 기둥, 여러 개 겹쳐 낄 수 있다) 중 일부. 세트 이름: 들판의 노래 · 버섯 숲의 축복 · 얼음 왕국 · 용암의 분노 · 마왕의 유산 (2·4·6개). 얻기: 제작 탭(지역별 섹션) / 상점 유물 소환(일반 60 · 희귀 30 · 영웅 10%, 겹치면 +1, 최대면 재료). 가방 탭: 칸 누르면 유물 창, 빈 칸·꾹 누르면 고르기, 다 차면 '바꿔 끼우기'로 뺄 유물 선택. 공짜 스킬 유물은 병아리 옆에 둥둥. 옛 장비는 저장 불러올 때 만든 값(+강화 절반씩) 재료·골드로 돌려준다, 장비 소환권 → 유물 소환권, 업적 '유물 수집'
- 스킬 미리보기: 지금 강화 단계(피해·속도·개수) 그대로, 피해 숫자는 실제 공격력, 아래에 '지금 강화 기준 (Lv n)' 요약. 몹 체력은 강화 전 기준이라 강화할수록 빨리 쓰러진다
- 스킬 NEW 표시: 스킬 탭을 보고 다른 탭으로 가면 전부 꺼진다
- 피격: 때린 쪽 반대로 넉백(320px/초, 금방 멈춤) + 0.6초 이동 속도 ×0.55 + 화면 테두리 빨갛게 + 빨간 조각·충격 고리 + 퍽 소리, 부딪힌 몹도 살짝 튕겨 나감 (보스 제외)
- 피격 세기 나눔: 일반 몹은 가볍게 (넉백 18 · 느려짐 없음 · 흔들림 0.6 · 테두리 0.2초). 보스·중간 보스(정예)는 넉백 320 · 0.6초 이동 ×0.55 · 흔들림 6 (히트 스톱·붉은 번쩍은 너무 세서 롤백). 빨간 테두리는 체력이 적을수록 진하고 넓고 검붉게
- 보스 타격감 (내가 보스·중간 보스를 때릴 때): 몸이 부르르 떨림 + 납작, 화면 살짝 흔들림(1.6, 치명타 3.5), 맞은 쪽에 큰 불꽃·충격 고리(치명타는 반짝), 큰 피해 숫자(15, 치명타 22), 둔탁한 타격음, 치명타면 0.035초 순간 멈춤(0.45초에 한 번). 효과는 0.07초에 한 번만 (탄이 많아도 과하지 않게)
- 탭화: 스킬 탭 = 위에 장착 칸 고정 + '📘 스킬 목록 / 🎁 스킬 상자' 보기 탭 (상자 쪽은 무료 상자 있으면 빨간 점, 튜토리얼은 상자 단계에서 자동으로 상자 보기). 제작 탭 = 위에 재료 고정 + '🔮 유물 제작 / 🧪 레시피' 보기 탭, 유물 제작은 지역 5개 탭 (초록 점 = 지금 만들 수 있음) → 세트 이름·보유 수·유물 6개·세트 효과. 마지막으로 본 보기 기억
