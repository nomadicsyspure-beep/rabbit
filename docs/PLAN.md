# 기획 메모

## 컨셉
병아리 용사가 평소엔 알아서 사냥하며 크고(방치), 중요한 순간엔 직접 들어가 싸운다(뱀서라이크).
핵심은 **방치 모드에서 키운 게 액션 모드에서 체감되는 것**.

## 핵심 루프
스테이지 직접 플레이(뱀서라이크) → 클리어하면 최고 스테이지 갱신 → 방치 수입 증가 → 능력치·스킬 강화 → 다음 스테이지 → (추후) 환생

- 방치 화면은 보여주기용. 스테이지가 바뀌지 않고, 최고 스테이지 기준 초당 골드만 쌓인다 (액션 중에도 쌓임)
- 스테이지는 1분: 60초 버티면 정예 몬스터 / 10단위 스테이지는 마왕 보스. 몹이 짙어지는 속도는 스테이지 길이와 상관없이 90초에 걸쳐

## 결정 사항
- 플랫폼: 모바일 브라우저, 세로 화면, 터치 기준 (PC는 WASD로 확인용)
- 아트: 주인공은 병아리. `art/source/chick`의 8방향 걷기·달리기 GIF를 `tools/chick_frames.py`로 정리해 쓴다 (멈춤은 걷기 첫 프레임, 쓰러짐은 눕힌 그림)
- 몬스터·스킬 이펙트·UI는 두 시트(`art/source/fx-sheet.webp`, `ui-sheet.webp`)에서 `tools/cut_sheets.py`로 잘라 쓴다. 시트에 없는 UI(도전 버튼, 강화 버튼 등)는 기존 것 그대로 둔다
- 몬스터 9종: 스테이지마다 일반/빠른/단단한 몬스터 외형이 바뀐다 (슬라임·박쥐·골렘 / 버섯·천사·달팽이 / 새싹·박쥐·골렘). 정예는 토끼 전사, 마왕은 악마. 쓰러지면 쓰러진 그림이 잠깐 남는다
- 배경은 흙바닥 (코드로 그린 무늬 + 시트의 돌·잎 장식)
- 이동은 출발할 때 느리게 시작해 가속한다 (최고 속도의 45%에서 출발, 약 0.3초 뒤 80%를 넘으면 달리기 그림). 방치 화면은 천천히 걸어서 걷기만
- 전체 템포는 빠르게, 몹은 많이·약하게: 쏟아지는 몹을 생각 없이 쓸어 담는 게 목표. 처치 때 쓰러진 그림·먼지·반짝임, 폭발·피격 때 화면 흔들림
- 스킬은 RPG처럼 영구: 골드로 배우고, 스킬 트리 3가지(피해 최대 30 / 발동 속도 최대 20 / 개수 최대 10)를 따로 강화하면 다음 스테이지에도 그대로. 스테이지에서는 장착한 8개만 자동 발동. 레벨업 카드(3택 1)는 없앴다
- 스킬 13종: 깃털 날리기·회오리·알 폭탄·화염 폭발·얼음 결정·치유·화염구·암흑 구체(UI 시트 아이콘) + 회전 베기·번개 연쇄·블랙홀·별똥별·빛의 기둥(이펙트 그림을 나무 틀에 넣은 아이콘)
- 밸런스보다 도파민: 장착 스킬이 많을수록 몹이 더 몰려오고, 처치마다 골드, 연속 처치 콤보 표시
- 캐릭터 레벨: 스테이지의 경험치 보석이 영구 경험치로 쌓인다. 레벨마다 공격력·체력 +5%
- 전투 엔진은 하나, 조종 주체만 다름 (AutoController / Joystick)
- 액션 모드는 공격 자동, 플레이어는 이동만. 플로팅 조이스틱
- 스테이지 설정 (저장됨): 왼쪽 위 AUTO = 플레이 전체 자동, 멀미 안 나게 최고 속도의 65%로 천천히 꺾으며 (몹 무리에 알맞은 거리로 붙어 둘레를 돌며 쓸고, 붙은 몹·보스는 피하고, 보물 상자를 주우러 감. 스킬도 자동. 조이스틱을 쓰면 그동안 직접 조종) / 아래 '스킬 자동·수동' = 수동이면 스킬 칸을 눌러야 발동 (암흑 구체는 늘 켜짐)
- 보물 상자: 스테이지에서 12초마다 근처에 나온다. 주우면 맵의 경험치 보석을 전부 끌어오고 골드 보너스
- 한 방향으로 꾹 누르기 방지: 움직이는 중엔 새 몹의 80%가 가는 방향 앞쪽에서 나오고, 멀어진 몹도 앞쪽으로 다시 온다. 같은 방향으로 1.5초 넘게 달리면 앞에 벽(2.5초마다), 방향을 안 바꾸면 벽이 점점 두꺼워지고 아파지며 두 번째부터는 정면 돌진 떼도 온다 (꾹 누르면 대략 10초면 쓰러짐). AUTO가 조종하는 동안은 이 벌칙에서 빠진다
- 몹 움직임: 일반은 옆으로 흔들리며 쫓아오고, 빠른 몹은 가는 길목을 앞질러 막는다
- 패턴 웨이브 (11초마다 돌아가며): 포위(빈틈 한 곳) / 돌진(옆에서 한 줄로 가로질러 감) / 벽(앞을 막음)
- 피버: (피버 중엔 AUTO로 천천히 움직여도 달리기 그림) 게이지가 처치 500마리만큼 차면(콤보와 상관없이 쌓이고, 피버가 끝나면 0부터) 10초 FEVER TIME. 장착 스킬 모든 가지(피해·발동 속도·개수) +5, 쿨다운 즉시 충전, 이동 속도 1.7배, 몹 2.5배, 피버 중 처치 골드 2배. 시간 아래 FEVER 게이지, 화면 테두리·병아리 금빛 (`src/modes/action.ts`의 FEVER_*)
- 타격감: 맞을 때 불꽃 파편, 치명타(15%, 피해 2배, 주황색 큰 숫자 + 더 세게 밀림), 맞은 몹이 납작해졌다 돌아옴, 쓰러질 때 몸 색 조각, 화염구·깃털 꼬리, 보석 주울 때 반짝, 100콤보마다 축하 연출, 번개는 빛나는 두 겹 선
- 몹 난이도 배율: 체력 ×1.25, 부딪힐 때 피해 ×1.1 (`src/modes/action.ts`의 MOB_HP, MOB_DMG)
- 테스트 중: 스킬 배우기·가지 강화 값은 전부 1골드 (`src/data/skills.ts`의 `COST_OVERRIDE`, null로 바꾸면 원래 값)
- 가로 모드는 스테이지에서만: '가로' 버튼이 전체 화면 + 가로 고정을 요청 (아이폰은 직접 돌리기). 가로 화면에선 왼쪽 절반 = 조이스틱, 오른쪽 = 스킬 칸 4×2 (두 손 조작). 메인 화면은 세로 그대로
- 장비 (`src/data/gear.ts`): 무기·모자·장신구 17종. 지역 재료 + 골드로 제작, +15까지 강화(+1마다 효과 15%↑). 무기 = 공격력% + 그 스킬을 공짜로 한 줄 더 쏨(장착 칸 안 씀), 모자 = 체력%, 장신구 = 자석·상자 등급·콤보 시간·치명타·피버 게이지·골드. 전설(마왕의 검·왕관)은 보스의 정수 필요. 그림 생기기 전까지 이모지 아이콘
- 스킬북: 블랙홀·별똥별·빛의 기둥은 📕 스킬북(상자에서 드랍)이 있어야 배움. 그 스킬을 주는 무기를 가지고 있으면 스킬북 없이 배움
- 도감: 처음 잡은 몬스터·처음 만든 장비 하나마다 공격력·체력 +1%
- 환생: 최고 스테이지 20부터. 골드·최고 스테이지·능력치 강화 초기화, 환생 깃털 획득 → 공격력 +10% / 골드 +15% / 경험치 +15% 영구 강화
- 동료 (`src/data/pets.ts`): 몬스터 그림을 그대로 쓰는 9종 (보통·희귀·전설). 하나만 데리고 다니고 방치·스테이지 둘 다 따라다님. 자석·골드·상자·체력·치명타·피버(능력치) / 박쥐 공격·버섯 포자 폭발·천사 회복(직접 행동). 소환으로 겹치면 레벨 업(최대 10)
- 상점 (`src/data/shop.ts`, `src/ui/shop.ts`): 다이아 소환(동료·장비, 1회 50 / 10회 450, 소환권 먼저), 병아리 색 8종(몸통 노랑만 색상 회전, 무지개는 시간에 따라 돈다), 스킬 이펙트 색 6종(이펙트 그림 색상 회전, `src/battle/tint.ts`), 다이아 충전(결제 준비 중)
- 광고 자리: 하루 10번. 상점 다이아 +30, 결과 화면 보상 2배, 오프라인 보상 2배. 지금은 2초 기다리면 바로 보상 (`playAd`만 광고 SDK로 바꾸면 됨)
- 미션 버튼(방치 화면 왼쪽 위, 받을 게 있으면 빨간 점): 일일 미션 6개 + 모두 완료 보너스, 7일 반복 출석, 단계별 업적 10종, 패스 30레벨(무료 보상, 프리미엄 줄은 결제 준비 중). 패스 경험치는 스테이지 도전·미션·업적으로
- 숫자 인플레이션 대응: 액션 모드는 방치 수치를 그대로 쓰지 않고
  **내 수치 ÷ 권장 수치 = 배율**(0.25~4배로 제한)로 환산해서 적용
- 탭 공격: 방치 화면을 탭하면 공격력의 50% 추가 피해
- 하단 탭 6개: 성장 / 스킬 / 장비 / 동료 / 던전 / 상점, 설정은 상단 아이콘
