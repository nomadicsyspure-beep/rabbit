# 기획 메모

## 컨셉
병아리 용사가 평소엔 알아서 사냥하며 크고(방치), 중요한 순간엔 직접 들어가 싸운다(뱀서라이크).
핵심은 **방치 모드에서 키운 게 액션 모드에서 체감되는 것**.

## 핵심 루프
스테이지 직접 플레이(뱀서라이크) → 클리어하면 최고 스테이지 갱신 → 방치 수입 증가 → 능력치·스킬 강화 → 다음 스테이지 → (추후) 환생

- 방치 화면은 보여주기용. 스테이지가 바뀌지 않고, 최고 스테이지 기준 초당 골드만 쌓인다 (액션 중에도 쌓임)
- 일반 스테이지: 90초 버티면 정예 몬스터 / 10단위: 180초 버티면 마왕 보스

## 결정 사항
- 플랫폼: 모바일 브라우저, 세로 화면, 터치 기준 (PC는 WASD로 확인용)
- 아트: 주인공은 병아리. `art/source/chick`의 8방향 걷기·달리기 GIF를 `tools/chick_frames.py`로 정리해 쓴다 (멈춤은 걷기 첫 프레임, 쓰러짐은 눕힌 그림)
- 몬스터·스킬 이펙트·UI는 두 시트(`art/source/fx-sheet.webp`, `ui-sheet.webp`)에서 `tools/cut_sheets.py`로 잘라 쓴다. 시트에 없는 UI(도전 버튼, 강화 버튼 등)는 기존 것 그대로 둔다
- 몬스터 9종: 스테이지마다 일반/빠른/단단한 몬스터 외형이 바뀐다 (슬라임·박쥐·골렘 / 버섯·천사·달팽이 / 새싹·박쥐·골렘). 정예는 토끼 전사, 마왕은 악마. 쓰러지면 쓰러진 그림이 잠깐 남는다
- 배경은 흙바닥 (코드로 그린 무늬 + 시트의 돌·잎 장식)
- 이동은 출발할 때 느리게 시작해 가속한다 (최고 속도의 45%에서 출발, 약 0.3초 뒤 80%를 넘으면 달리기 그림). 방치 화면은 천천히 걸어서 걷기만
- 전체 템포는 빠르게, 몹은 많이·약하게: 쏟아지는 몹을 생각 없이 쓸어 담는 게 목표. 처치 때 쓰러진 그림·먼지·반짝임, 폭발·피격 때 화면 흔들림
- 스킬은 RPG처럼 영구: 골드로 배우고 강화(최대 20레벨)하면 다음 스테이지에도 그대로. 스테이지에서는 장착한 4개만 자동 발동. 레벨업 카드(3택 1)는 없앴다
- 스킬 8종 (UI 시트 아이콘과 1:1): 깃털 날리기·회오리·알 폭탄·화염 폭발·얼음 결정·치유·화염구·암흑 구체
- 캐릭터 레벨: 스테이지의 경험치 보석이 영구 경험치로 쌓인다. 레벨마다 공격력·체력 +5%
- 전투 엔진은 하나, 조종 주체만 다름 (AutoController / Joystick)
- 액션 모드는 공격 자동, 플레이어는 이동만. 플로팅 조이스틱
- 숫자 인플레이션 대응: 액션 모드는 방치 수치를 그대로 쓰지 않고
  **내 수치 ÷ 권장 수치 = 배율**(0.25~4배로 제한)로 환산해서 적용
- 탭 공격: 방치 화면을 탭하면 공격력의 50% 추가 피해
- 하단 탭 6개: 성장 / 스킬 / 장비 / 동료 / 던전 / 상점, 설정은 상단 아이콘

## 프로토타입(v0.3) 범위
- 방치: 보여주기용 자동 전투, 탭 공격, 최고 스테이지 기준 초당 골드, 스탯 4종(공격력·체력·공격 속도·이동 속도), 오프라인 보상(최대 8시간, 50%)
- 스킬 탭: 8종 배우기·강화·장착(4칸)

- 던전 탭: 다음 스테이지 도전, 일일/주간(잠금)
