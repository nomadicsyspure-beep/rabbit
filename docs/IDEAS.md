# 성장·BM·콘텐츠 아이디어

지금 상태: 스테이지 1분 동안 몹을 쓸어 담는 재미는 충분하다. 부족한 건 **스테이지 밖에서 키울 것**과 **돈·시간을 쓸 곳**.
아래는 제안이고, 맨 아래 "추천 순서"대로 하나씩 붙이는 걸 권한다.

> **진행 상황: 아래 제안은 전부 들어갔다** (그림은 임시 이모지·기존 몬스터 그림). 남은 건 맨 아래 "필요한 그림"과 결제 연결. 광고 보상은 빼기로 했다.
> 실제 구현 내용은 `docs/PLAN.md`의 결정 사항 참고.

## 1. 보물 상자 → 재료 상자, 싹쓸이는 다른 방식으로

### 재료 상자
- 스테이지 중 나오는 상자를 줍으면 **장비 재료**가 나온다 (보석은 더 이상 안 끌어옴)
- 상자 등급: 나무(흔함) / 은(가끔) / 금(정예·마왕 처치, 피버 중 확률 ↑)
  - 등급이 높을수록 재료 개수·희귀 재료 확률 ↑
- 재료는 스테이지 구간마다 다르게: 1~10 `깃털 조각`, 11~20 `버섯 포자`, 21~30 `골렘 돌` … → 장비 단계와 연결
- **연출**: 줍는 순간이 아니라 **결과 화면에서 상자를 연다** (탭 → 흔들림 → 펑 → 재료가 튀어나옴). 열기 연출 자체가 도파민이고, 나중에 "상자 즉시 열기 / 추가 상자" BM으로 이어짐

### 싹쓸이 (보석 전부 끌어오기) 대안
| 방식 | 느낌 | 비용 |
|---|---|---|
| **A. 피버 시작 때 자동 싹쓸이** | 피버의 쾌감에 보석 회수까지 겹침 | 거의 없음 (지금 코드 재사용) |
| **B. 100콤보마다 싹쓸이** | 콤보를 이어갈 이유가 하나 더 생김 | 거의 없음 |
| C. 자석 스킬 (장착 칸 차지, 쿨다운) | 선택지가 됨 | 스킬 1개 추가 |
| D. 자석 펫 (주기적으로 끌어옴) | 펫 시스템과 함께 | 펫 시스템 필요 |

→ **A + B 먼저** (바로 가능), 펫이 생기면 D 추가.

## 2. 성장 방향: 재료 → 장비 → 스킬

```
스테이지 ──→ 골드·경험치·재료 상자
   │              │
   │        ┌─────┴─────┐
   ▼        ▼           ▼
 능력치    장비 제작/강화   스킬북(드물게)
 강화        │             │
            ▼             ▼
       스킬 해금·강화 ←─ 장비가 스킬을 바꾼다
```

- **장비 3부위**: 무기 / 모자 / 장신구
  - 무기: 기본 공격(지금 깃털) 자체를 바꾼다 — 깃털 지팡이(깃털), 불꽃 막대(화염구 기본), 번개 부채(연쇄 기본) …
  - 모자: 외형 + 능력치 (모자는 머리 좌표에 얹는 방식, 예전에 얘기한 고정점 방식)
  - 장신구: 특수 효과 (피버 게이지 +20%, 상자 등급 ↑, 콤보 유지 시간 +0.5초 …)
- **장비가 스킬을 연다**: 강한 스킬(블랙홀·별똥별·빛의 기둥)은 골드로 못 배우고, 해당 계열 장비를 끼거나 **스킬북**이 있어야 배울 수 있게 → 재료를 모을 이유
- **장비 강화**: 재료 + 골드로 +1 ~ +15, 일정 단계마다 옵션 추가. 실패 없는 강화로 스트레스 줄이기
- **환생**(나중): 최고 스테이지 기준으로 `환생 깃털`을 받고 처음부터. 깃털로 영구 배율 → 방치형의 장기 성장 축
- **도감**: 처음 잡은 몹·처음 얻은 장비 등록 → 소소한 영구 능력치

## 3. 재화 쓸 곳 (BM 후보)

| 쓸 곳 | 내용 | 그림 필요 |
|---|---|---|
| **병아리 색 바꾸기** | 색만 바꾼 스킨 (분홍·민트·검정·금색 병아리). 그림은 코드로 색 변환이라 거의 공짜 | 없음 |
| **모자 꾸미기** | 왕관·밀짚모자·마법사 모자… 5방향 그림 | 모자 그림 |
| **스킬 이펙트 스킨** | 같은 스킬, 다른 색 (보라 회오리, 파란 화염구) | 없음 (색 변환) |
| **펫** | 따라다니며 보조 공격 / 자석 / 회복. 펫도 레벨업 | 펫 그림 (한 장 + 뒤집기) |
| **무기** | 위 2번의 무기 | 무기 아이콘 |
| **상자 열쇠** | 재료 상자 추가로 열기, 즉시 열기 | 열쇠 아이콘 |
| **소환(가챠)** | 장비·펫 뽑기. 천장 있는 방식 | 소환 연출 |
| **광고 보상** | 스테이지 보상 2배, 오프라인 보상 2배 | 없음 |
| **패스** | 매일 접속·미션 보상 단계 | UI |

→ 돈 안 드는 것부터: **병아리 색 · 이펙트 색**은 그림 없이 바로 가능.

## 4. 스테이지 다양화

- **지역(10스테이지마다)**: 흙바닥 → 숲 → 눈밭 → 화산 → 어둠의 성
  - 바닥 색·무늬와 장식만 바꿔도 분위기가 크게 다름 (지금 흙바닥도 코드로 그린 것)
  - 지역마다 몹 구성·마왕이 다름
- **스테이지 규칙(가끔 붙는 변형)**
  - 빠른 몹만 / 단단한 몹만 / 정예 다수 / 안개(시야 좁음) / 폭탄 몹(죽으면 터짐)
  - **황금 몹**: 드물게 등장, 잡으면 골드 폭죽 → 쫓아가는 재미
- **목표 다양화**: 버티기(지금) / 시간 안에 N마리 / 보물 지키기 / 도망치는 황금 병아리 잡기

## 5. 고난도 맵 "보스 레이드"

- 잡몹 거의 없음, **보스 1마리**와 1:1. 피하는 게 핵심
- 보스 패턴 (예고 후 공격)
  - 장판: 바닥에 원이 깜빡이다 터짐
  - 탄막: 회전 탄, 부채꼴 탄
  - 돌진: 예고선 → 빠른 돌진 (지금 마왕에 있음)
  - 소환: 잠깐 잡몹 소환
  - 2페이즈: 체력 50% 이하에서 패턴 빨라짐·추가
- 보상: **특수 재화 `보스의 정수`** → 최상급 장비·전설 스킬·한정 모자
- 하루 3회 / 주간 순위(최단 처치 시간)
- 이미 있는 던전 탭의 `주간 던전` 자리에 넣으면 됨. `일일 던전`은 재료 던전(재료 상자 많이 나오는 맵)

## 6. 그 밖의 콘텐츠

- **무한 모드**: 얼마나 오래 버티나 (최고 기록·순위)
- **일일 미션 / 출석 / 업적**: "콤보 1000 달성", "피버 3번" 같은 목표 → 매일 들어올 이유
- **이벤트 스테이지**: 주말 황금 병아리 이벤트 (골드 3배)
- **사운드**: 맞을 때 톡, 잡을 때 퐁(콤보가 오를수록 음이 올라감), 피버 팡파르 — 도파민에 그림만큼 큼. 소리 파일 없이 코드로 만들 수 있음

## 추천 순서

1. **싹쓸이 A+B** (피버 시작·100콤보) + **재료 상자** + 결과 화면 상자 열기 연출
2. **장비 3부위** (제작·강화) + 장비로 강한 스킬 해금
3. **일일 던전(재료)**, **보스 레이드(특수 재화)**
4. **병아리 색·이펙트 색** (그림 없이 가능한 꾸미기)
5. **펫**, 소환(가챠), 광고 보상
6. 지역 테마·스테이지 규칙, 미션·출석, 사운드

## 필요한 그림 (요청 목록)

같은 스타일(두꺼운 갈색 외곽선, 부드러운 명암)로, 투명 배경이면 좋음.

1. **재료 아이콘** 6~8종 (깃털 조각, 버섯 포자, 골렘 돌, 얼음 결정, 용암석, 어둠의 조각 …) — 작은 아이콘
2. **상자 3종** (나무·은·금) + 가능하면 열린 모습
3. **장비 아이콘**: 무기 3~5, 모자 3~5, 장신구 3~5
4. **모자 외형**: 병아리 5방향(아래·오른쪽 아래·오른쪽·오른쪽 위·위)에 맞춘 모자 2~3종 (왼쪽은 뒤집어 씀)
5. **펫** 2~3종 (한 장씩, 옆모습 또는 정면)
6. **보스 레이드용 보스** 1종 (걷기 + 공격 예고 + 쓰러짐)
7. **새 스킬 5종 아이콘** (회전 베기·번개 연쇄·블랙홀·별똥별·빛의 기둥 — 지금은 이펙트 그림을 틀에 넣어 씀)
8. (선택) 지역 바닥 타일: 숲·눈밭·화산
